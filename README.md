# sunflower

an open source Luau executor for Mac. 

# operation

- download **Xcode** if you haven't....
- open `.xcodeproj` and change anything
- & then build and have fun with it!

# prerequisite

- basic knowledge of *objective C*
- intel based Mac (x86_64)


# history
